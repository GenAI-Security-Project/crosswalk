AI Security Standards Crosswalk

25 industry security, compliance, and AI-governance frameworks — mapped control-by-control to Gen AI and Agentic security risks by the OWASP GenAI Security Project.

A "crosswalk" maps controls, clauses, or entries in one framework to their equivalents in another. GenAI Crosswalk answers two questions: given a Gen AI or Agentic AI security risk, which controls in a given framework address it? — and the reverse, given a compliance framework you must satisfy, which AI-specific risks does it actually cover? This page lists all 23 frameworks currently mapped against the OWASP LLM Top 10, the OWASP Top 10 for Agentic AI, and DSGAI (Data Security for GenAI), with 3,211 individual control mappings.
